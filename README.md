# TFM: Kinetic modeling of plasma instabilities in a Hall thruster discharge

MSc thesis code: a 1D-azimuthal, collisionless particle-in-cell (PIC) model of the electron cyclotron drift
instability (ECDI) and anomalous electron transport in Hall thrusters, written in Python.

- `docs/scope.md`: scope, validation case and roadmap
- `docs/notation.md`: symbols and code names
- `docs/decisions.md`: numerical choices and open questions
- `prototypes/`: exploratory scripts (P0: 1D electrostatic periodic PIC with conservation diagnostics)

Run the prototype: `python prototypes/conservation_test.py`
