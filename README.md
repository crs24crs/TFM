# TFM: Kinetic modeling of plasma instabilities in a Hall thruster discharge

MSc thesis code: particle-in-cell (PIC) simulation in Python.

- `prototypes/` — exploratory scripts (1D electrostatic periodic PIC with conservation diagnostics)
- `docs/notation.md` — symbols and code names
- `docs/decisions.md` — numerical choices and open questions

Run: `python prototypes/conservation_test.py`
